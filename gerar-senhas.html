Gerador de senhas

Transforma as senhas em hashes PBKDF2. Só o hash vai para o config.js — a senha em si nunca aparece no código.
Este navegador não liberou o crypto.subtle aqui. Abra este arquivo pelo endereço do site (https) em vez de dois cliques no arquivo, ou use o Chrome.
Use senhas de 10 caracteres ou mais, com letra, número e símbolo. Senha curta ou só de números é quebrada em minutos por quem baixar o código.
Pronto. No config.js, apague as duas últimas linhas (export const PIN_HASH… e export const ADMIN_HASH…) e ponha estas no lugar.

  
  
Depois de colar, as senhas de teste (1010, 2020…) param de valer sozinhas.


  Anote as senhas num gerenciador. Não dá para recuperá-las a partir do hash: se perder, é só gerar de novo.
